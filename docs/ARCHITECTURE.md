# 总体架构（冻结基线）

当前只冻结下列结构和模块边界，不实现完整能力：

1. **PySide6 桌面层（后续）**：负责本地交互、进度和人工审核入口。
2. **核心服务层**：编排模块调用，不直接绑定具体模型或界面。
3. **FFmpeg 媒体服务**：负责探测、切片、转码、音频提取和字幕烧录。TASK-001 已建立最小实现，默认只使用项目内 `tools/ffmpeg/bin`，不依赖系统 PATH。
4. **本地 ASR 适配层**：隔离不同本地语音识别实现。
5. **在线 LLM 适配层**：隔离在线分析提供商；是否启用、费用和密钥必须由用户明确配置。
6. **SQLite 内部状态**：保存应用内部任务状态和索引，不替代模块间公开契约。
7. **JSON 模块接口**：使用版本化的 `timeline.json`、`current_analysis.json`、`review_current.json` 交换可审计数据。
8. **统一任务服务**：统一长任务的状态、进度、取消、错误和恢复语义。

以上是 TASK-000 的结构基线。实现技术、线程模型、数据库表、界面布局、模型选择和 API 提供商均未冻结。

## TASK-001 媒体服务边界

`src/liveclip/media/` 当前包含：

- `ffmpeg_paths.py`：固定项目内工具路径并支持显式配置覆盖；
- `process_runner.py`：argv 子进程、超时、退出码、UTF-8/GB18030 输出与结构化错误；
- `probe.py`：只解析 ffprobe JSON，形成容器、时长、轨道和编码结构；
- `audio.py`：输出 PCM s16le、16 kHz、单声道 WAV；
- `trim.py`：使用 CPU libx264 + AAC 对非整数区间精准重编码；
- `subtitles.py`：纯 Python SRT 解析、边界裁剪、重新计时和 libass 烧录；
- `validate.py`：导出后存在性、ffprobe、轨道、时长、编码和 SRT 边界校验；
- `outputs.py`：同目录临时文件、非覆盖保护和原子发布。

媒体操作不直接结束宿主 Python 进程，调用方通过返回对象或结构化异常处理失败。所有产出先写唯一临时文件，再以不覆盖既有目标的方式发布。TASK-001 未引入 UI、ASR、语义分析、数据库或任务调度实现。
