# ASR 20窗口本地人工听音指南

## 1. 打开审核页面

审核包生成后，使用 Chrome 或 Edge 直接打开：

```text
<LOCAL_REVIEW_OUTPUT>\review.html
```

无需本地服务器、网络、账号或插件。不要把 `review.html`、`clips/`、`review-data.json` 或整个审核目录上传到网盘、GitHub、聊天工具或其他网络服务。

## 2. 播放与切换窗口

- 点击页面顶部或侧边的窗口编号进入对应窗口。
- 使用音频播放器试听；每段在原审核窗口前后默认各增加 0.8 秒，首尾会自动限制在源 WAV 范围内。
- 使用“上一个”“下一个”切换，也可启用“仅显示未完成”。
- 顶部“已完成 X/20”显示当前进度。

## 3. 选择最佳结果

先听音频，再比较 SenseVoice、Paraformer 和 Faster-Whisper 文本：

- 某一模型明显最好时选择对应模型；
- 两个或三个结果质量相当时选择“并列”；
- 三个结果都无法使用时选择“都不可用”。

这一步是人工判断。页面不会计算准确率、CER/WER或自动宣布模型冠军。

## 4. 错误严重度

每个模型都必须选择一个严重度：

- `0`：无明显错误；
- `1`：有轻微错误，但主要信息和阅读基本不受影响；
- `2`：有明显错误，信息或可读性受到实质影响；
- `3`：严重错误或结果不可用。

“最佳结果”和三项严重度都填写后，才能勾选“本窗口已完成”。

## 5. 实际听写与可选字段

- 当三候选都有关键错误、需要说明正确内容，或以后可能制作人工参考文本时，填写“实际听写文本”。
- 可按模型选择漏字/漏词、多字/幻觉、错字/替换、专名、英文、数字、标点、异常字符、切点/分段等错误标签。
- 音频本身含糊、重叠、噪声过大或确实听不清时，勾选“音频难以辨认”。
- 备注只记录判断所需信息，不写个人隐私或凭据。

## 6. 保存、清空与恢复

- 页面在每次修改后使用浏览器 `localStorage` 自动保存。
- “手动保存”可立即写入本地浏览器存储。
- 清空操作需要连续两次确认。
- 更换浏览器、浏览器配置或清理站点数据可能使 localStorage 失效，因此建议定期导出草稿 JSON。
- 使用“导入 JSON”可恢复同一个审核包导出的草稿或完成文件；未知、重复窗口及非法候选/严重度会被拒绝。

## 7. 导出文件

未完成20个窗口时，页面导出：

```text
asr-human-review-draft.json
asr-human-review-draft.csv
```

全部完成后，页面导出：

```text
asr-human-review-completed.json
asr-human-review-completed.csv
```

浏览器通常保存到系统“下载”目录。可将文件移动到受控的本地目录，例如 `<LOCAL_REVIEW_OUTPUT>\exports\`；不要提交到 Git。

## 8. 完成后交给 Codex 的文件

完成20个窗口后，保留并交给 Codex：

```text
asr-human-review-completed.json
```

CSV 便于人工查看，但后续结构化复核以完成版 JSON 为主。交接时不要附带 `clips/` 音频目录。

## 9. 当前阶段边界

本审核页是 TASK-002 技术验证后的本地人工证据工具，不是正式产品界面。当前任务不运行 ASR 模型、不调用云端、不修改模型结果、不计算最终准确率，也不执行 TASK-003。
