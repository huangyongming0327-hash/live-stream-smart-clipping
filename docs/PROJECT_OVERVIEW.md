# 项目概览

## 项目目标

直播智能切片是一个 Windows 本地优先的桌面项目，目标是把直播长视频转换成可追踪、可人工审核的短视频候选。原始视频始终由用户控制，中间模块通过版本化 JSON 契约解耦。

## 当前范围

当前只处于技术验证阶段。TASK-000 仅建立：

- 安全且可扩展的目录骨架；
- 本机环境诊断基线；
- `timeline.json`、`current_analysis.json`、`review_current.json` 三个 Pydantic 数据契约；
- 离线测试框架。

## 明确不在当前范围

- 不实现桌面界面或完整业务流程；
- 不处理真实视频；
- 不安装 FFmpeg；
- 不下载 ASR/LLM 大模型；
- 不调用任何收费 API；
- 不开始 TASK-001。

## 目录职责

- `src/liveclip/`：源代码和模块边界。
- `tests/`：无需网络的契约测试。
- `docs/`：架构、决策、状态和环境报告。
- `runtime/`：可清理的日志、缓存和临时文件。
- `项目/`：本地项目数据。
- `模型/`：未来经许可下载或导入的本地模型。
- `设置/`：本机私有设置；真实设置不提交 Git。
- `samples/`：未来放置小型、可公开的测试样本。
- `tools/`：项目维护和诊断脚本。
