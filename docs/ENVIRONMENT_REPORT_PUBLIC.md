# 公开环境摘要

原私有环境报告主要记录单台 Windows 机器的解释器位置、用户目录、PATH、磁盘卷、可用空间和工具安装路径。为避免公开个人路径和机器指纹，原始环境快照没有复制到公开工作副本。

公开可复现边界如下：

- 操作系统目标为 64 位 Windows。
- Python 支持范围为 `>=3.11,<3.14`；已验收技术基线使用 Python 3.12。
- 项目采用本地优先存储，运行数据、缓存、模型和用户媒体均位于用户自行选择的项目外或忽略目录。
- 测试脚本只修改其子进程环境，不修改 Machine/User PATH 或全局 Git 配置。
- FFmpeg 作为项目本地外部工具使用，但二进制不随仓库分发。
- ASR 模型和独立运行环境不随仓库分发，也不会由 GitHub Actions 下载。

具体本机用户名、用户目录、磁盘容量、工具绝对路径、Machine/User/Process PATH、机器名和网络信息均已排除。
